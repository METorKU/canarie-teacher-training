// FOR TEACHERS

Build your own grading assistant.

The AGENTS.md and SKILL.md template from Designing Assessments and Feedback with AI. Fill it in once with your rubric, and Codex grades homework and drafts feedback the way you do.

Download the template (ZIP) ↓
// 5 STEPS

Get started.

  1. UNZIP

    Unzip the file

    Inside canarie-teacher-training-main are two folders: template is yours to fill in, demo is the IELTS example from the session.

  2. OPEN

    Open the template folder in Codex

    Open the template folder itself, not the folder above it. If Codex asks to trust the folder, say yes.

  3. EDIT

    Fill in each [EDIT]

    In AGENTS.md: your class. In SKILL.md: the homework, your rubric, 2 or 3 pieces you already marked, and the feedback language. SKILL.md is in the hidden .agents folder; on a Mac, press Cmd + Shift + . in Finder to see it.

  4. GRADE

    Add student work and ask Codex to grade

    Type “Create data/homework.csv and add these 3 pieces of work.”, then “Grade homework hw1-s01, hw1-s02 and hw1-s03.” Use codes, never names.

  5. REVIEW

    Read the feedback

    Open the feedback folder. PDFs or photos instead of a CSV? Make a homework folder inside template with one file per student, named with a code such as hw1-s01.pdf.

You are still the marker. Check every score and comment before students see it.
